## Randomness Testing Undergraduate Challenge
This repository contains all the necessary materials to play the randomness testing challenge. 

### The directory structure is as follows:
**Rules.pptx** Explains the format of the challenge and background information about each of the tests.
**NISTCodeExplanation** Explains how to utilize the NIST code suite to perform the tests on the provided bitstreams.
**Bitstreams** contains the generated random numbers to test with the NIST code suite.
**Generators** contains the flawed Python code for analysis.

### Prerequisites 
If choosing to run the NIST test suite on the provided bitstreams, you will need a way to compile and run C code.
